# Arkanoid — контекст проекта

Браузерный арканоид (breakout), чистый JS + Canvas 2D, без сборщика и фреймворков.
Начат ~2022 (см. `git log`), не закончен, сейчас в рабочей копии лежит незакоммиченный
рефакторинг (старый `element.js` удалён, логика объектов разнесена по классам в `objects/`).

## Запуск
Сборки нет — просто открыть `index.html` в браузере (или поднять любой статический
сервер, т.к. современные браузеры иногда режут `file://` для модулей/запросов).

## Структура файлов
- `index.html` — разметка (меню, экраны победы/поражения, canvas) + порядок `<script>`.
  **Важно:** это classic-скрипты без модулей, порядок подключения в html критичен:
  `config.js → ParentObject.js → Stick.js → Position.js → Boll.js → Enemy.js → Player.js → game.js → index.js`.
- `index.css` — стили игрового экрана, поверх `bootstrap.css` (вендорный файл, подключён целиком).
- `index.js` — обработчики UI: кнопки меню, старт/рестарт, переключатель "два игрока",
  кнопка "назад в меню".
- `game.js` — инициализация игры, игровой цикл (`requestAnimationFrame` + `setTimeout`
  для ограничения FPS), отрисовка (`draw`), обработка клавиатуры, состояние (жизни/очки).
- `objects/config.js` — все глобальные `let`-переменные игры (canvas, context, player,
  player2, boll, enemys, score, health, exit, debugUpdate, fps, level, enemyMap) +
  объект `config` (стартовые размеры/скорости) + хелперы (`incScore`, `desHealth`,
  `getRandomArbitrary`).
- `objects/ParentObject.js` — базовый класс: позиция, цвет, AABB-пересечение (`intersects`),
  заглушки `draw/go/checkPosition/changeVector/touch`.
- `objects/Stick.js` — базовый класс для "палок" (платформа/кирпич): столкновение с мячом
  с отскоком под углом в зависимости от точки удара (`touch`).
- `objects/Player.js extends Stick` — платформа игрока: плавное движение на клавиши
  (`keydownLeft/Right`, `keyup`), инерция через `velocity`.
- `objects/Enemy.js extends Stick` — кирпич: своя версия `touch()` с AABB-определением
  стороны удара, становится `invisible` после попадания, даёт очки.
- `objects/Boll.js extends ParentObject` — мяч: скорость, движение, отскок от стен,
  потеря жизни при вылете за нижнюю границу, рестарт позиции над платформой.
- `objects/Position.js` — маленький value-object для x/y (используется при рестарте мяча).

## Игровой цикл
`init_game(level)` (game.js) → фиксирует внутреннее разрешение canvas 600×400 (CSS только
масштабирует), создаёт `player`/`player2`/`boll`/`enemys`, запускает `update()`.
`update(time)` — `requestAnimationFrame`; логика (`step()`) идёт фиксированными шагами
`1000/fps` мс (fps = 60), поэтому скорость не зависит от частоты монитора; затем `draw()`.
Победа — все кирпичи `invisible`, поражение — `health <= 0` (проверки в `step()`).
Клавиатура вешается один раз в `index.js` → `handle_key()` (стрелки / `KeyA`,`KeyD`).

## Враги / уровень
`init_enemies()` раскладывает кирпичи по `enemyMap` (ячейка `1` — кирпич) один раз при
старте, ширина кирпича считается так, чтобы ряд занимал всю ширину canvas.
Если `enemyMap` falsy — сетка из `enemyLen` кирпичей по `config.enemy.cols` в ряд.

## Режимы
- Один игрок — управление стрелками.
- Два игрока (переключатель в меню, `window.isTwoPlayer`) — второй игрок на `a`/`d`,
  у игроков общий мяч, общий счёт/жизни (кооператив, не раздельные составы).
