# Arkanoid — открытые проблемы

Критичные баги (замирание мяча, краш при потере мяча, сложность, дубли обработчиков
и игровых циклов при рестарте, невидимые кирпичи, скорость от частоты монитора,
наложение платформ в режиме двух игроков, искажение при ресайзе) исправлены.

Осталось / идеи:
1. Нет touch/мобильного управления — только клавиатура.
2. Нет сохранения рекорда между сессиями (localStorage).
3. После потери жизни мяч сразу вылетает — можно ждать нажатия пробела.
4. Classic `<script>` в строгом порядке в `index.html` — при росте проекта
   стоит перейти на ES-модули.
5. `.idea/` стоит добавить в `.gitignore`.
